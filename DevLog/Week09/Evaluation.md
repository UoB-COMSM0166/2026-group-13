# Evaluation 
To evaluate our game, we conducted a user study comparing two levels (Level 1 and Level 2), aiming to assess usability, workload, and overall gameplay experience. Both qualitative and quantitative methods were used, including the System Usability Scale (SUS), NASA Task Load Index (NASA-TLX), and statistical testing.

## 1. Qualitative evaluation 
From a qualitative perspective, most users found Level 1 intuitive and easy to understand, making it suitable as an introductory level. Players reported that they could quickly grasp the basic controls and mechanics, which provided a smooth learning experience. In contrast, Level 2 was perceived as more challenging and required more strategic thinking, particularly in using the recording system effectively. Several participants noted that the recording mechanic was innovative and engaging, but some found it initially difficult to fully understand. This suggests that while the mechanic adds depth to gameplay, clearer guidance or tutorial elements could improve usability. Additionally, some users reported confusion when interacting with clones, indicating potential issues with feedback clarity and system consistency.
