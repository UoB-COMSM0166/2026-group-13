# U Help U — Presentation Script (Bilingual)

## 开场白

## Opening

各位老师好，我们是第十三组。我们的游戏叫 U Help U，是一款 2D 平台解谜游戏。
Hello everyone, we are Group 13. Our game is called U Help U, a 2D platform puzzle game.

这是一款解谜游戏而不是普通的平台跳跃游戏。
This is a puzzle game, not an ordinary platformer.

需要玩家理解机制才能过关。
Players must understand the mechanics in order to clear each level.

## 核心玩法演示

## Core Gameplay Demo

（直接让老师开始玩）
(Invite the teachers to play directly.)

为了节约时间老师可以游客登录。
To save time, teachers may log in as a guest.

（打开账号登录页面 → 以游客身份登录）
(Open the account login page → log in as a guest.)

（打开 Easy 模式第一关）
(Open Easy Mode Level 1.)

为了让新玩家能够快速上手，我们在第一关加入了新手教学。
To help new players get started quickly, we included a tutorial in the first level.

首先是基本的移动和跳跃提示。（渐变提示效果）
First come the basic movement and jump prompts. (Fade-in hint effect.)

（打开设置）也可以去设置页面改键位。
(Open Settings.) Players can also remap controls in the settings page.

玩家可以自己去看顶部UI自己摸索如何玩。
Players can observe the top UI and figure out the mechanics on their own.

但为了方便新手玩家更好地理解机制，我们有一个逐步的教程系统，会自动高亮关键区域，帮助玩家理解。
But to help beginners understand the mechanics more easily, we have a step-by-step tutorial system that automatically highlights key areas.

（打开教学系统）
(Open the tutorial system.)

由于时间有限，我们就不让老师自己看了，我来简单讲解。（关闭教学系统）
Due to time constraints, we won't have the teachers read through it — I'll give a brief explanation instead. (Close the tutorial system.)

按下 C 键 开始录制，此时所有操作都会被记录。
Press **C** to start recording; all actions from this point will be captured.

上方的 UI 会显示倒计时，时间轴也会显示录制的动作。
The top UI shows a countdown, and the timeline displays the recorded actions.

录制结束后，按 R 键 回放，就会出现一个与主角外形相同的幻影，它会精准重复刚才的动作。
After recording ends, press **R** to replay — a phantom identical in appearance to the protagonist will appear and precisely repeat the recorded actions.

如果对录制不满意，可以再次按 C 键 清空并重新录制。（演示）
If you are unsatisfied with the recording, press **C** again to clear it and re-record. (Demo.)

我们幻影是无敌的！
Our phantom is invincible!

要通过这扇门，必须有人一直按着按钮保持门开启。
To pass through this door, someone must continuously hold down the button to keep it open.

所以我们需要召唤一个幻影，让它重复我们按下按钮的动作。
So we need to summon a phantom to repeat the action of pressing the button.

趁幻影按着按钮时，我们就能快速通过大门。
While the phantom holds the button, we can quickly pass through the gate.

这就是我们的核心玩法，之后所有关卡都围绕它展开。
This is our core mechanic, and all subsequent levels are built around it.

有了幻影的协助，我们就能轻松通过第一关。（邀请老师尝试或自行演示）
With the phantom's help, we can easily clear Level 1. (Invite teachers to try, or demo yourself.)

（通过第一关）
(Clear Level 1.)

## 第一个技术难点：排行榜与账户系统

## Technical Highlight #1: Leaderboard & Account System

（展示第一关排行榜）
(Display the Level 1 leaderboard.)

每次通关后，都会显示排行榜，展示前十名玩家的通关时间。
After each level is cleared, the leaderboard is shown, displaying the top 10 players' completion times.

如果玩家没有进入前十，也会显示：
If a player does not make the top 10, the following information is still shown:

- 本次用时 / Current run time
- 个人历史最短用时 / Personal best time
- 最高排名 / Personal best ranking

（根据老师昵称展示数据）
(Display data based on the teacher's nickname.)

无论是游客还是注册用户，数据都会上传到服务器，由后端自动处理排序。
Whether guest or registered user, data is uploaded to the server and sorted automatically by the backend.

排行榜中带皇冠图标的表示注册用户，没有皇冠的是游客。
A crown icon on the leaderboard indicates a registered user; no crown means a guest.

重名会自动加序号，避免冲突。
Duplicate names are automatically given a number suffix to avoid conflicts.

（回到关卡选择界面）
(Return to the level selection screen.)

玩家也可以随时改名。如果新名字已被使用，也会自动加上序号。
Players can change their name at any time. If the new name is already taken, a number suffix is added automatically.

改名后，排行榜中的显示会同步更新。
After renaming, the leaderboard display updates in sync.

（打开所有排行榜界面）
(Open the full leaderboard view.)

这里可以看到所有关卡的排行榜，刚刚修改的名字也已经更新。
Here you can see the leaderboards for all levels, and the name change is already reflected.

## 其他玩法

## Additional Gameplay

为了让玩家保持新鲜感，我们简单关卡中每一关都有新的元素和机制。
To keep players engaged, each level in Easy Mode introduces a new element or mechanic.

并且我们的解谜也不是唯一的解法。
Also, our puzzles do not have a single solution.

（打开 Easy 模式第四关）
(Open Easy Mode Level 4.)

演示第一个部分有两种解法，我们更推荐老师之后去自己体会我们的游戏。
Demonstrating that the first section has two solutions — we encourage teachers to explore the rest of the game on their own.

我们还有很多谜题。
There are many more puzzles to discover.

这里先自己演示一下。
Let me demo this part first.

一个是按按钮跳平台过去，一个是自己垫着自己跳过去。
One solution is to press the button and jump across the platforms; the other is to use yourself as a stepping stone to jump over.

刚才展示的都是简单模式。
Everything shown so far has been in Easy Mode.

而困难模式则会综合多种机制。
Hard Mode combines multiple mechanics.

所有关卡的整个平均游玩时长2个小时，但如果很聪明的话可能一个小时。
The average total playtime across all levels is about 2 hours, though very skilled players may finish in around 1 hour.

例如困难模式第三关（打开 Hard 模式第三关）：比如这关我们就有5个难点（puzzle）。
For example, Hard Mode Level 3 (open it): this level alone contains 5 distinct puzzles.

（可以开编辑器模式给老师看第二面）
(Editor mode can be opened to show teachers the second section.)

第一个难点我们实际上有3个解法，但是每个解法都蛮有难度的！（可演示1种解法）
The first puzzle actually has 3 solutions, but each one is quite challenging! (Demo one solution.)

我们希望老师可以自己去体会所有游戏，每个困难关卡开发中起码测试了20遍以上，目前没有发现任何bug了。
We hope teachers will explore the full game themselves. Each Hard Mode level was tested at least 20 times during development, and no bugs have been found so far.

这款游戏本质上是 Puzzle Game，重点在于"思考"。
This game is fundamentally a Puzzle Game — the focus is on _thinking_.

玩家能否通关，主要取决于对机制的理解和策略规划。
Whether a player can clear a level depends primarily on their understanding of the mechanics and strategic planning.

如果理解到位，通关会很顺利；否则可能会在同一处卡很久。
If they understand well, progress will be smooth; otherwise, they may get stuck at the same spot for a long time.

因为我们游戏是准备上架的，并且已经把目前的demo上传到itch了，所以我们关卡每一关都有好好的打磨，没有重复的puzzle，我们不喜欢让玩家重复同一种操作，变成纯粹的操作跳跃游戏，很枯燥。
Because we plan to publish this game and have already uploaded the current demo to itch.io, every level has been carefully refined. There are no repeated puzzles — we don't want players repeating the same action over and over, turning it into a pure platformer, which would be boring.

## 第二个技术难点：关卡编辑器与共享

## Technical Highlight #2: Level Editor & Sharing System

接下来介绍另一个重要功能——关卡编辑器与共享系统。
Next, let me introduce another important feature — the Level Editor and Sharing System.

我们刚开始只是为了设计关卡方便。
We originally built it just to make level design easier.

后来加入了上传功能。
Later, we added an upload feature.

玩家可以随时使用内置编辑器创建自己的关卡。
Players can use the built-in editor at any time to create their own levels.

编辑器支持放置地形、机关、按钮、门、传送门等元素，玩家可以自由组合，设计完全不同的解谜体验。（随便拖几个元素）
The editor supports placing terrain, traps, buttons, doors, portals, and more. Players can mix and match freely to design entirely different puzzle experiences. (Drag a few elements to demo.)

（给老师演示上传和保存功能）
(Demo the upload and save features for the teachers.)

玩家编辑完成后，可以一键上传到共享区。（展示上传按钮与命名）
Once players finish editing, they can upload their level to the shared area with one click. (Show the upload button and naming field.)

其他玩家可以在 Map Plaza 模式中搜索并游玩这些地图。（打开 Map Plaza）
Other players can search and play these maps in Map Plaza mode. (Open Map Plaza.)

玩家在编辑器中看到的是可视化的方块和机关，但上传时必须转换成结构化的数据格式。
What players see in the editor is a visual layout of blocks and mechanisms, but on upload it must be converted into a structured data format.

服务器收到后需要正确解析，其他玩家下载时也必须百分之百还原原作者的布局。
The server must parse it correctly, and when other players download it, the original author's layout must be reproduced with 100% accuracy.

我们做了大量测试，确保：
We conducted extensive testing to ensure:

- 每个元素的位置、类型、参数都被准确记录
- Every element's position, type, and parameters are accurately recorded
- 数据格式稳定、可扩展
- The data format is stable and extensible
- 下载后不会出现错位、丢失或逻辑错误
- No misalignment, missing elements, or logic errors occur after downloading
